# 最小评测

在项目根目录运行 `python evals/evaluator.py` 会真实执行全部 18 个问题，调用聊天 API，按模型选择访问 Steam 和 Embedding API。可能产生 API 使用量，不自动重试。

`python -m unittest -v` 只运行离线模拟测试，不代表真实 Agent 效果。

工具选择按实际开始执行的工具集合比较，忽略顺序；Trace 另外记录模型请求的工具。抓取和 RAG 次数按尝试计数，失败也计入。纯知识问题要求零次抓取；成功的 Steam 工具要求一次抓取。

自动失败追加到 badcases.json，保留历史；损坏的历史文件会报错，不覆盖。每次真实运行还保存独立 report_时间.json，包含所有答案，供人工复核。请勿并发运行多个评测进程。

18 个用例均需人工复核事实和语义。规则仅发现明显断言；否定或引用语境标记复核，不简单按敏感词判失败。自动通过不代表排名数字、关注标签或完整语义正确。没有 Steam 工具却回答实时排名会触发工具选择失败；完整数字核对仍需人工对照当次数据。

人工流程：查看失败分类和原答案 → 分析原因 → 手动修改提示词、知识或代码 → 重跑评测。程序不自动修改任何规则或提示词，不使用 AI Judge。
